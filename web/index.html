Bend Reality — off-axis cylinder demo
Drag in the 3D view to orbit. Add projectors and tune each one's pose; set Blend widths where beams overlap. Every projector is warped to the Eye-point sweet spot, so the Eye View from that point composites the enabled projectors — straight grid and an invisible seam means a correct warp and blend. Uncheck Warp follows projector and move a projector to see the mis-calibration appear in the Eye View. Projector Output shows the active projector's emitted image.
